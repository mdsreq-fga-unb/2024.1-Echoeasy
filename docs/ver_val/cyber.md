## 1. Introdução
Este documento trata da verificação e validação do PBB apresentado no estudo de caso "HealthNet", realizado pelo grupo CyberHunterz e que pode ser acessado clicando [aqui](https://mdsreq-fga-unb.github.io/2024.1-ObjeX/healthnet-pbb/). A técnica de checklist foi utilizada para conduzir a atividade e abaixo pode-se visualizar as checklists de verificação e validação.

## 4. Validação do PBB
| Pergunta                                                                                         | OK? |                                                            Observação                                                            |
| ------------------------------------------------------------------------------------------------ | --- | :------------------------------------------------------------------------------------------------------------------------------: |
| Os problemas foram identificados?                                                                | ✅  |                                                                                                                                  |
| A estrutura do PBI está correta e devidamente priorizada?                                        | ❌  |           Apesar da priorização ter sido feita, não está devidamente priorizado no PBI: a estrutura precisa de ajuste (detalhado na verificação)         |
| O Backlog montado está alinhado com o PBB Canvas?                                                | ❌  |                                                   Nao foi encontrado o backlog                                                   |
| As features seguem o mesmo padrão?                                                               | ❌  |                                            Verbos estão conjugados de forma diferente                                            |
| As historias estão diretamente relacionadas aos problemas e benefícios apresentado nas features? | ✅  |                                                                                                                                  |
| As historias de usuário seguem o mesmo padrão?                                                   | ❌  | "Algumas USs não estão em seu devido padrão. Uma US segue o padrão: ""Eu como <persona>, quero <ação> para <valor de negócio>""" |
| Todas as personas  foram identificadas?                                                          | ✅  |                                                                                                                                  |
| Os objetivos e atividades de cada persona foi identificado?                                      | ✅  |                                                                                                                                  |
