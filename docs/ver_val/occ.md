## 3. PBB (Product Backlog Building)
A seguir, apresentam-se as tabelas de verificação e validação relacionadas ao processo de Product Backlog Building (PBB). Essas tabelas incluem as perguntaras que serão avaliadas, uma seção para confirmação (check) indicando se cada item está em conformidade, e um campo de observações destinado ao registro de eventuais apontamentos caso algum item não atenda aos critérios estabelecidos.

### Verificação PBB
| Pergunta                                                                                     | OK? | Observação |
| -------------------------------------------------------------------------------------------- | --- | :--------: |
| Os problemas foram identificados?                                                            | ✅  |            |
| As features demonstram os problemas que serão resolvidos e os benefícios que a persona terá? | ✅  |            |
| Os críterios de aceitação das historias de usuários estão definidas?                         | ✅  |            |
| As historias de usuário seguem o padrão quem, o que, por que?                                | ✅  |            |
| As features seguem o padrão de verbos conjugados no infinitivo?                              | ❌  |            |
| Cada PBI está vinculado a uma feature?                                                       | ✅  |            |
| Cada PBI está seguindo o modelo ARO?                                                         | ✅  |            |
| A estrutura do PBI está correta e devidamente priorizada??                                   | ✅  |            |
| O backlog está priorizado utilizando os PBIs e alguma técnica de priorização?                | ✅  |            |

### Validação PBB

| Pergunta                                                                                         | OK? | Observação |
| ------------------------------------------------------------------------------------------------ | --- | :--------: |
| Os problemas identificados são condizentes com a realidade?                                      | ✅  |            |
| O Backlog montado está alinhado com o PBB Canvas?                                                | ✅  |            |
| Todas as personas  foram identificadas?                                                          | ✅  |            |
| As historias estão diretamente relacionadas aos problemas e benefícios apresentado nas features? | ✅  |            |
| Os objetivos e atividades de cada persona está condizente com a realidade?                       | ✅  |            |


## 4. USM (User Story Mapping)
A seguir, apresentam-se as tabelas de verificação e validação relacionadas ao processo de User Story Maping (USM). Essas tabelas incluem as perguntaras que serão avaliadas, uma seção para confirmação (check) indicando se cada item está em conformidade, e um campo de observações destinado ao registro de eventuais apontamentos caso algum item não atenda aos critérios estabelecidos.

### Verificação USM

| Pergunta                                                                                                     | OK? | Observação                                                                                       |
| ------------------------------------------------------------------------------------------------------------ | --- | :-----------------------------------------------------------------------------------------------: |
| As Personas estão devidamente identificadas?                                                                 | ✅  |                                                                                                  |
| O USM está no devido padrão? (objetivos, jornada do usuário, tarefa de usuário)                              | ✅  |                                                                                                  |
| Há separação das tarefas em iterações?                                                                       | ❌  | Só foi identificado tarefas para o MVP                                                           |
| O USM está seguindo um padrão linguístico? (verbos no infinitivo)                                            | ✅  |                                                                                                  |
| Existe uma sequência lógica nas atividades?                                                                  | ✅  |                                                                                                  |
| Nos cards de título de tarefa de usuário exitem as USs?                                                      | ❌  | Ao expandir cada card das tarefas de usuário não há história de usuário definida apenas o título |
| As histórias de usuários estão devidamente escritas? (eu como <cargo>, quero <ação> para <valor de negócio>) | ❌  | Não há histórias de usuário                                                                      |

### Validação USM

| Pergunta                                                                                                                      | OK? | Observação                  |
| ----------------------------------------------------------------------------------------------------------------------------- | --- | --------------------------- |
| Os objetivos do usuário e do negócio estão alinhados?                                                                         | ✅  |                             |
| Os objetivos abrangem o que o usuário deseja alcançar?                                                                        | ✅  |                             |
| A jornada do usuário abrange o que o usuário faz no produto?                                                                  | ✅  |                             |
| Os usuários seguem os passos descritos na jornada do usuário?                                                                 | ✅  |                             |
| Os objetivos, a jornada e as tarefas de usuário estão claros e compreensíveis para pessoas fora da equipe de desenvolvimento. | ✅  |                             |
| A partir do USM as histórias de usuário podem ser criadas?                                                                    | ✅  |                             |
| As história de usuário estão relacionadas ao seu título?                                                                      | ❌  | não há histórias de usuário |
