# Definition of Done (DoD)

Trata-se de um conjunto de critérios ou condições que uma tarefa ou história de usuário deve atender para ser considerada finalizada e completa. Ao contrário do DoR, que se concentra nos requisitos para que uma tarefa esteja pronta para o desenvolvimento, o DoD especifica os critérios que devem ser cumpridos para garantir que a tarefa está concluída de forma adequada e pronta para ser entregue.

Abaixo está o checklist que define os critérios que uma contribuição precisa atender para ser marcada como "Pronto":

1. <b>Atendimento aos Critérios de Aceitação:</b> A User Story deve satisfazer todos os critérios de aceitação estabelecidos.
2. <b>Integração Completa:</b> Se aplicável, deve haver integração entre o backend e o frontend deve estar completa e funcionando conforme esperado.
3. <b>Testes de Sistema:</b> Todos os testes de sistema devem ser executados e aprovados, garantindo que o sistema funcione conforme especificado.
4. <b>Implementação:</b> Se aplicável, a funcionalidade deve estar implementada tanto na versão web quanto no aplicativo móvel.
5. <b>Validação do Cliente:</b> A funcionalidade deve ser revisada e aprovada pelo cliente ou pelo responsável pela aceitação.
